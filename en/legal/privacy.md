# Privacy Policy

*YouTube Optimizer — a private tool of the Lifechanyuan Encyclopedia*

**What this is.** YouTube Optimizer is a small private tool used only by the owner of the Lifechanyuan Encyclopedia YouTube channels, to manage the owner's own videos: titles, descriptions, thumbnails, playlists and publishing schedules. It is not offered to the public and has no other users.

**What data it accesses.** With the owner's permission, it uses the YouTube Data API to read and update information about videos on the owner's own YouTube channels. It does not access, collect or store personal data about any other person.

**Where data is kept.** Authorization tokens are kept only on the owner's own computer. Nothing is sent to any server operated by us, and nothing is shared with, sold to, or transferred to any third party.

**Use of Google user data.** The tool's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements, and complies with the [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service) and the [Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access.** The owner can revoke the tool's access at any time at [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions).

**Changes.** If this policy changes, the new version will be posted on this page.
