# 智阵与智慧阵

**三十六道八卦阵里有两个与"智"有关的阵，讲的不是一回事。**第六阵智阵，讲人想成为智者的心理：智者是花朵不是果实，人人都想成为智者，这个心理把人关进求智的阵里。第十七阵智慧阵，讲智慧这件工具：给人以自由意志，让人用智慧创造去满足欲望，智慧玩不好，会成为吞噬人的东西。
