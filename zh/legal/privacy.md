# 隐私政策

*YouTube Optimizer——生命禅院百科馆的一个私人工具*

**这是什么。** YouTube Optimizer 是一个小型私人工具，只供生命禅院百科馆 YouTube 频道的所有者管理自己的视频使用：标题、简介、封面、播放列表和定时发布。它不向公众提供，没有其他用户。

**访问哪些数据。** 经所有者授权，它通过 YouTube Data API 读取和更新所有者自己频道上的视频信息。它不访问、不收集、不存储任何其他人的个人数据。

**数据存放在哪里。** 授权令牌只保存在所有者自己的电脑上。不会发送到我们运营的任何服务器，也不会与任何第三方共享、出售或转让。

**对 Google 用户数据的使用。** 本工具对来自 Google API 的信息的使用和转让，遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)（包括“有限使用”要求），并遵守 [YouTube API 服务条款](https://developers.google.com/youtube/terms/api-services-terms-of-service) 和 [Google 隐私权政策](https://policies.google.com/privacy)。

**撤销授权。** 所有者可随时在 [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions) 撤销本工具的访问权限。

**变更。** 本政策如有变更，会发布在本页。
